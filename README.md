## Problem statement
Urban drivers often waste time and fuel searching for available parking, especially near markets, colleges, offices, and hospitals. Information about parking availability, prices, and restrictions is fragmented or outdated.

## Project objective
Use user-centred design to understand drivers' needs before proposing a solution. This repository contains two evidence-informed sample personas, an empathy map, key pain points, and design opportunities.

## Proposed concept
**ParkEase** — a hypothetical parking-discovery experience that helps drivers compare nearby parking options, view reported availability and prices, and navigate to a selected location. This is a concept for design exploration, not a deployed service.

## Repository contents
- `index.html` — interactive project page with personas, empathy map, insights, and design opportunities.
- `styles.css` — responsive styling.
- `script.js` — persona switcher and empathy-map interaction.
- `report.md` — concise written report.
- `assets/` — reserved for project assets.

## Run locally
Open `index.html` in any modern browser. No installation or internet connection is required.

## Research note
The personas and empathy map are **illustrative hypotheses**, not the results of interviews or a statistically representative study. Validate them with real users before making product decisions.

## Suggested next steps
1. Interview 5–8 drivers with varied travel patterns.
2. Observe a busy parking location at different times.
3. Validate the most frequent pain points and willingness to use a parking-discovery tool.
4. Prototype the highest-priority flow and test it with users.
